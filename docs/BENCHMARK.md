Ranking by people rescued: utility 90.2% , goal-based 87.8%, reflex 53.7%. The expected order (utility >= goal >= reflex) holds on average.

Reading the columns: the utility agent deliberately rescues the most at-risk person first, which often costs more path than grabbing the nearest one, so a higher cost next to a higher rescue count is the trade-off working, not a defect. "Replans" counts dropped or replaced plans for the utility agent and changes of destination mid-walk for the other two.
